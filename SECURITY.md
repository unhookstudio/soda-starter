# Security policy

## Supported version

Security fixes are applied to the current `main` branch. There is no backport or
compatibility guarantee for older revisions while the backend rewrite is in
progress.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue, discussion, or pull request containing exploit details, suspected
credentials, personal data, or unredacted logs.

Include the affected revision, impact, reproduction conditions, and a minimal
proof of concept when safe. You should receive an acknowledgement within seven
days, but this project has no contractual response or remediation SLA.

If private vulnerability reporting is unavailable, do not publish the report;
wait for the repository owner to enable a private reporting route.
